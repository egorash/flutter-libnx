## 1. Готово

**Build-цепочка macOS (`macos-plan.md`, этапы 0–7):**
- Форк/bootstrap, аудит скриптов, окружение, проверка `.sh`.
- Engine checkout, сборка движка + sqlite3, порт PowerShell → bash.
- Сборка до `.nro` (в т.ч. `examples/my_nexus`), сборка произвольного
  приложения.

**Приложение `my_nexus` на железе:**
- Старт, сплэш, UI, авторизация — работают (после точечного TLS-обхода
  `*.my-nexus.ru`, см. `docs/horizon-tls-roots.md`).
- Фаза 0 (телеметрия каналов) пройдена полностью — коммиты `3486f68`,
  `d6c1a6e`.
- Реализованы в эмбеддере: `path_provider`, `shared_preferences`,
  `flutter_secure_storage`, `url_launcher`, `file_picker`, `hive` (pure
  Dart), FFI-мост sqlite3, `textinput` (swkbd), видео-текстуры media_kit.

**Git-структура форка** — нормализована: `master` = default, feature-ветки
отведены от него, PR — внутри форка.

**Плагины звука и геймпада (2026-10-16)** — работают на железе на
`examples/romashka_game`:
- `audioplayers` — MP3 через `audren`, декодер minimp3, ресемплинг
  44,1 → 48 кГц, 32 голоса, возврат голоса по завершении;
- `gamepads` — кнопки и стики через плагин, D-Pad и стик клавиатурным
  путём, вибрация;
- `tools/hw_probe` — измерительный прибор без Flutter и Dart: тон 440 Гц
  и сырая маска кнопок;
- `FLUTTER_LIBNX_AUDIO_TRACE=1` — трассировка микшера (по умолчанию выкл).

Ключевые исправления: `62910ca` (аудио), `be4c02c` (геймпад). Подробности
и грабли — `docs/journal-audio-gamepad.md`.

## 3. Отложено / осознанно пропущено

- **`app_links`** — пропущен: ошибка ловится приложением, deep links не
  используются.
- **`connectivity_plus` / `package_info_plus`** — игнор: прямых вызовов нет.
- **DNS `EAGAIN` плиток карты** — ~100 параллельных lookup
  `*.basemaps.cartocdn.com` → `errno=11`. Отложено, задокументировано.
- **Фаза 4 (вне области):** встроенный WebView как view, камера, GPS-железо,
  биометрия.
