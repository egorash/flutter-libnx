## 3. Отложено / осознанно пропущено

- **`app_links`** — пропущен: ошибка ловится приложением, deep links не
  используются.
- **`connectivity_plus` / `package_info_plus`** — игнор: прямых вызовов нет.
- **DNS `EAGAIN` плиток карты** — ~100 параллельных lookup
  `*.basemaps.cartocdn.com` → `errno=11`. Отложено, задокументировано.
- **Фаза 4 (вне области):** встроенный WebView как view, камера, GPS-железо,
  биометрия.

  заглушка.

  регистранте.
